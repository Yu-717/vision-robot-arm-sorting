# Atlas 200I DK A2 智能机械臂套件项目

这是后续机械臂套件开发的工作区。当前课堂项目约 14 周，常规实物验证每周约 2 小时；第一目标是四种垃圾图案贴纸积木的识别、桌面定位、抓取和分类投放。2026-09-26 已用 `src/pipeline/run.py` 实机跑通“扫描 → 四类识别 → 抓取 → 分类放置”的第一阶段闭环；第二阶段目标是板上 NPU 推理、容器投放和更多垃圾种类。

**从 [Atlas 200I DK A2 工作区总览](docs/atlas-200i-dk-a2/README.md) 开始。**其中包含设备、课程与案例、运动学/相机/NPU 代码地图、官方来源和实施基线。

## 遥控与几何预演

新增本地工作台：`python3 src/teleop/server.py`，打开 <http://127.0.0.1:8765/>。默认离线模拟，支持关节点动、腕部相机视锥、场景物块、冻结帧平面标定与采样。

[使用说明、当前记录索引和实机边界](docs/atlas-200i-dk-a2/08-遥控与场景标定工作台.md)。本次只完成离线验证，未执行实机动作。
