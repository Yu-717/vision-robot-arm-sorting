# 多视角方块定位离线实验

日期：2026-09-20。**这是纯合成几何实验，不是当前机械臂或相机的精度测试。**脚本不导入 `Arm_Lib`，不连接板卡，也不发送运动命令。

## 已知资料与模拟假设

课程资料在 `资料/课程说明/第二阶段-机械臂基础控制/01-组件介绍及远程连接.txt` 第 201–210 行描述了 USB RGB 相机：30 万像素、640×480、约 110° 视场角和 30 fps。资料未说明 110° 是水平、垂直还是对角视场角，也未提供当前设备的相机内参、镜头畸变或逐像素深度。这里**暂假设 110° 是水平视场角**，采用无畸变针孔相机。实际镜头较广，现场应重新标定，不能将这个假设当作真实内参。

[模拟参数](../../config/multiview_synthetic.json)中的三个位姿、方块尺寸和位置均为假设，单位为米。相机沿一条横向路径拍三张图，视线都指向同一个桌面区域；方块顶面有一条带方向的红边，用于区分方块朝向。[三张合成画面](multiview_synthetic_views.svg)只显示理想投影，不代表真实相机成像。

## 方法

1. 按已知的相机位置、朝向和假设内参，将 4 cm 方块的顶面四角投影到每张 640×480 图像。
2. 给每个角点的 `u`、`v` 独立加入标准差为 1.5 像素的高斯误差。模拟中角点身份和跨帧对应关系事先已知；真实图像必须另外完成检测与匹配。
3. 对已知方块顶面高度，先用单帧的相机射线与该高度平面求交，作为基线。对未知高度，每个对应角点由两条或三条相机射线做最小二乘三角化。四角均值作为顶面中心，已标识的第一条边给出桌面平面内的朝向。
4. 固定随机种子重复 1000 次，比较单帧已知高度、两帧、三帧，以及把真实假设 110° 误写成 105° 时的结果。两帧完全重合时会拒绝三角化，因为没有视差。

完整运行结果在 [JSON](multiview_results.json) 中。位置误差是顶面中心的三维欧氏距离，不等于实际夹取误差。

| 模拟条件 | 位置误差中位数 | 位置误差第 95 百分位 | 朝向误差中位数 |
|---|---:|---:|---:|
| 1 帧，顶面高度精确已知 | 1.874 mm | 3.815 mm | 4.300° |
| 2 帧，使用正确的模拟内参 | 8.776 mm | 25.026 mm | 13.103° |
| 3 帧，使用正确的模拟内参 | 4.337 mm | 12.451 mm | 7.341° |
| 3 帧，把 110° 视场角当成 105° | 8.538 mm | 14.046 mm | 7.343° |

在**顶面高度确实已知**的假设下，单帧平面求交反而比从少量宽视角画面估计未知深度更精确；实际高度一旦设错，单帧结果会产生系统偏差。未知高度时，第三帧在此场景下降低了随机角点误差，但错误内参造成的系统偏差不会靠多拍一帧自动消失。结果受假设的相机间距、方块距离、角点噪声和完美跨帧匹配影响，不能外推成硬件性能。

## 重跑

在项目根目录执行（仅需 Python 标准库）：

```bash
python3 src/spatial/multiview_demo.py \
  --svg-output docs/experiments/multiview_synthetic_views.svg \
  > docs/experiments/multiview_results.json
python3 -m unittest discover -s tests -p 'test_multiview_demo.py' -v
```

可以编辑模拟配置里的方块位置、相机间距和视场角做敏感性实验。配置强制标识为 `synthetic_assumptions`，避免被误当作实机标定。代码仅实现几何投影、单帧平面求交和多视角三角化；目前没有真实图像的角点检测、相机畸变校正、相机到机械臂的手眼标定，也没有从关节回读推算每帧相机位姿。

下一次实物验证要同步记录每帧原图、时间戳和关节回读，测量方块及标定板尺寸，标定相机内参与畸变和相机相对机械臂的安装位姿，并用多个独立测量点报告实际误差。若相机始终停在同一姿态，重复 2–3 帧只能减小检测噪声，不能三角化出新的度量深度。
