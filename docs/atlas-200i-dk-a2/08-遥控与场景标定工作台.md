## 启动离线工作台

在项目根目录执行：

```sh
python3 src/teleop/server.py
```

打开 <http://127.0.0.1:8765/>。加载历史照片的演示方式：

```sh
python3 src/teleop/server.py \
  --replay data/captures/2026-09-24/map_v2_placed.jpg
```

历史图显示“历史静态图”，不随模拟关节变化，也不代表当前相机位置。界面左侧“腕部相机·理想投影”才是当前模拟姿态的预期画面。

## 已实现的操作

### 关节遥控与反馈

- 每次只点动一个关节 ±1° 或 ±2°，六个角度一起写入；不排队，不支持按住连续发送。
- 使用当前回读构造目标；复用现有软限位、整段路径禁入区检查、批量写和回读核对。
- 展示当前六轴角、命令目标、回读时间、估计末端/相机位置、最小模型余量。
- 启动默认锁定；实机还需页面现场确认和带采集时间的有效相机画面。
- 单页面操作权，有 2 秒心跳租约。后台、失焦、Esc、停止按钮会禁止后续指令；超时不可用心跳自行恢复，必须重新使能。
- 回读失败或超差时停止后续指令。**本遥控器不会自动退回上一姿态**：既有 `safe_arm.run_segments` 有自动退回行为，而本模块只复用校验和底层 `Arm`，避免停止后又增加一个未经观察的动作。原函数保持原样。
- 同时持有 `safe_arm` 的进程锁，防止与遵守同一锁的脚本并发。直接调用 Arm_Lib 的第三方脚本不受该锁管理，现场必须关闭其他控制程序。

停止按钮不等于急停，已下发的一步可能继续完成；本次没有定义或使用 `Arm_Action_Mode(0)` 作为急停。

### 前端几何与相机

- 可拖动旋转、滚轮缩放；显示连杆、关节、基座坐标轴、夹爪与相机光心、视锥。
- 前端正解与 Python 正解有对照测试。相机位姿用 `base_T_gripper × cam2gripper`，包含第五轴旋转导致的侧向偏移变化。
- 视锥使用现有暂定内参，640×480、水平视场 36.3°。模拟相机是理想针孔投影，不模拟镜头畸变、遮挡和光照。
- 显示地图码位置、−10 cm 桌面、平台禁入区和可增删的立方体；物块可设置 X/Y、边长、绕 Z 转角。地图平移 Y+8 cm 为手量初值。
- “独立姿态预演”提供六轴滑条，同时锁定点动；只改变画面，退出后恢复实际/模拟后端读数。预演不执行运动、不证明路径安全。
- 指间开口是与夹爪角度相关的示意比例，尚不是角度—宽度实测模型；模拟物件也不参与安全碰撞判定。

### 采样、平面标定与测量

1. 在回读稳定且无动作时，保存边界观察、物件、抓取观察或示教参考位；记录关节角、模型坐标、画面及其时间、文字备注。
2. 冻结一张照片。在同一平面的四周选至少 4 个点，填写像素 U/V 与实测 X/Y（cm），最多 30 点。
3. 拟合平面单应矩阵。共线/退化点拒绝。四点的零残差只是拟合结果，不是定位精度证明；须用未参与拟合的点核验。
4. 测量该冻结帧上的坐标或两点距离。每次拟合独立存档，测量记录包含对应标定 ID。
5. 新冻结帧使当前标定失效；只允许在原冻结帧上使用原映射。相机、平面移动后要重新标定。

物块顶面与桌面高度不同，桌面映射不能直接用于顶面尺寸。工作台没有自动估高、手眼再标定或自动抓取规划。

## 相机接入

板载相机已有带 `X-Frame-Time` 的 HTTP 快照服务，可接：

```sh
python3 src/teleop/server.py --camera-url http://192.168.137.100:8080/snapshot.jpg
```

此命令仍然是模拟机械臂，只接入真实画面。HTTP 源必须返回 JPEG；采集时间来自服务端头字段。运行在 Mac 上时要保证时钟与相机服务可比，实机控制建议在板上运行工作台和相机服务。

RTSP 使用本机 `ffmpeg` 转为浏览器可显示的 JPEG。私有地址可在本地设置环境变量 `ARM_CAMERA_URL`，然后执行 `python3 src/teleop/server.py`，避免写入项目文件和日志。不要把含密码的 URL 发到对话。当前工作台不会显示或保存该 URL；ffmpeg 本地进程参数仍会包含源地址。

**RTSP 目前仅作监看与采样。** 解码接收时间无法证明相机真实采集时间，本版不会仅凭 RTSP 收到新数据就允许实机点动。实机安全门要求板载 HTTP 快照的采集时间，2 秒内有效；回放图也不能满足实机安全门。RTSP 实际连接、时延和断线行为本次未验证。

## 后续现场使用实机入口

本次没有部署。将新 `src/teleop/` 和现有 `src/adapters/`、`src/spatial/`、`config/` 保持目录结构复制到板上应用目录后，使用能导入 `Arm_Lib` 的解释器。以下是现场准备好后的入口：

```sh
/root/miniconda3/envs/ros-arm-env/bin/python src/teleop/server.py \
  --hardware --execute --camera-url http://127.0.0.1:8080/snapshot.jpg
```

服务只监听板卡回环地址。在 Mac 上另开 SSH 转发，端口保持相同：

```sh
ssh -N -L 8765:127.0.0.1:8765 root@192.168.137.100
```

然后打开本地地址。需要先停止占用 8765 的本地模拟服务。启动硬件模式只读当前角度，页面确认并点动才写入。板上没有相机服务时，先按原有部署文档启动相机服务，不能把本地旧帧当成新帧。

首次现场验证应为空载、1° 单步，从安全姿态开始，逐项观察方向、相机时序、回读、停止与失联。平台实际尺寸、连杆/夹爪外壳包络、第五轴线缆与夹爪持续夹持仍需现场核验。**本版不提供降低桌面余量、越过禁入区、自动下探或一键抓取按钮。** 现有 2.5 cm 桌面余量与 3 cm 物块精确抓取之间的适配尚未验收，需要完成独立抓取模式与夹持验证后再开放。

## 文件与证据

默认会话写入 `data/teleop/日期_时间_随机后缀/`：

- `session.json`：配置、手眼/内参/地图快照、模式与源类型。
- `events.jsonl`：使能、指令、回读、拒绝/异常、停止记录，含限位配置 SHA-256。
- `samples.jsonl`、`sample_*.jpg`：人工采样、独立的画面时间与姿态回读时间。
- `frame_*.jpg`、`calibration_*.json`：冻结帧和独立版本的平面映射。
- `measurements.jsonl`：像素、换算坐标、距离及标定 ID。

界面可导出本次内存中的采样/标定/测量 JSON；图片仍在会话目录中。不会覆盖 `config/calibration/`。重启后以磁盘记录为证据，尚无会话导入界面。
