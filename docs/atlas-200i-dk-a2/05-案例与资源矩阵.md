## 当前项目建议优先复用

1. 用第二阶段课程和 `Arm_Lib.py` 确认控制接口，但所有动作经本机限幅、回读和人工监督。
2. 用流水线 Notebook 的预处理/NMS 和本地 OM 做旧四色基线；采集四张**垃圾图案贴纸**后建立新标签与模型。
3. 从已归档的官方分拣工程研究十字板、透视变换、URDF、IK 和抓放流程；逐项验证与当前硬件/固件是否一致。
4. 基础抓取稳定后再选择手势、跟拍、流水线或传感器扩展，不把仅有视频的案例写成已实现功能。
