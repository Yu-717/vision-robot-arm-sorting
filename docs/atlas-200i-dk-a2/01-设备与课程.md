# 设备、产品与课程

## 套件组成与接线

官方[产品介绍](../../资料/官方资料/Atlas-200I-DK-A2-机械臂/产品介绍-23.0.RC3.pdf)给出的 **DK A2 开发者套件**基本规格是 8 TOPS INT8、4 TFLOPS FP16、4 GB LPDDR4X、4 个 1.0 GHz CPU 核；板上有 2 个千兆网口、2 个 USB 3.0 Type-A、1 个 USB Type-C、40Pin、2 个 MIPI-CSI、Micro SD 和 M.2 扩展，12 V 供电、典型功耗 24 W。该规格指本套件，不能与其他 20 TOPS 的 Atlas 200I A2 模组型号混用。文档还列出 Ubuntu 22.04/openEuler 22.03 选项；当前实机系统为 Ubuntu 22.04.2。

官方[机械臂开发指南](../../资料/官方资料/Atlas-200I-DK-A2-机械臂/机械臂应用开发指南-23.0.RC3.pdf)第 2 章的样例由 Atlas 200I DK A2 开发者套件及其电源、机械臂及独立电源、USB 摄像头、地图/标定板、连接排线、网络和 SD 卡构成。开发板与机械臂分别供电；摄像头连接板卡 USB 并固定在机械臂上；40Pin 排线连接机械臂扩展板。实际安装方式、相机相对末端的位姿和线缆活动范围仍须现场记录。

先前调研依据物料链接、扩展板和 API 推断机械臂**可能**是 Yahboom DOFBOT 无主板套装；官方指南没有明确把当前设备品牌型号写成已核实事实。采购时需按接口、供电、舵机和固件兼容性核对。

| 组件 | 本机状态 | 证据和注意点 |
|---|---|---|
| Atlas 200I DK A2 / 昇腾 310B | 已连接，NPU 状态 OK | [2026-09-18 实测](../05-板卡连接与硬件实测.md)；4 GB 级内存条件下应实测同时运行的峰值资源 |
| 机械臂扩展板与六路舵机 | 扩展板版本 0.20，1–6 号 ping 正常 | `Arm_Lib 0.0.5` 使用 I²C-7、地址 `0x15`；1–5 号单写异常待查 |
| USB 相机 | `/dev/video0`、`/dev/video1` 已枚举，640×480 采集成功 | 摄像头索引、分辨率、镜头参数和安装位姿待固化；两设备节点不等于两台相机 |
| 夹爪 | 6 号舵机有单写和回读证据 | 开合量、夹持力与积木尺寸未标定，不能用角度命令代替抓取成功证据 |
| 标定板/地图 | 官方方案依赖十字框平面 | 实物尺寸、固定方式和有效工作区待现场测量 |

课程说明给出的机械限位为 1、2、3、4、6 号 0–180°，5 号 90–270°。底层驱动对部分上限有检查，但未覆盖所有负值/物理干涉，应用层还需独立限幅；[实测安全边界](../05-板卡连接与硬件实测.md)优先于各 Notebook 的大角度示例。

## 与本项目任务的对应

课程旧样例以颜色块为目标，现项目以**四种垃圾图案贴纸**为目标。现阶段应先确认四张贴纸的类别定义、积木实际尺寸、容器位置和相机可见范围，再采集当前场景图像。若仅复用旧四色模型，演示可能跑通颜色分拣，却不能证明垃圾图案识别已经完成。

数据需求原文还提到手势 `fist/like/ok/palm`、正常/大笑表情、WFLW 人脸关键点等；这些属于扩展，不占用基础抓取的早期现场验证时间。课程对深度相机没有现成前提，因此第一版空间定位按已知桌面平面设计，三维抓取是后续独立验收项。
